Install packages from requirements.txt

Run the project with python manage.py runserver and head to the locally hosted url

Insert your username and personal token (link to retrieve personal token attached to lichess form page)

Optionally:
    - Enter game mode - default is all (multiple inputs to be added)
    - Enter number of games you would like to retrieve - default is 20000 (this number is total games, not per game mode)
    - Enter Opening - default is all (multiple inputas to be added)
